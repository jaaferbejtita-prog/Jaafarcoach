Avant le lancement

Les produits sont-ils déjà disponibles ?

Pas encore. Le site est en phase de pré-lancement. Les emplacements sont prêts pour le vrai stock, les vraies photos et les vrais prix.

Les images actuelles resteront-elles ?

Non. Elles servent uniquement à poser l’identité visuelle et seront remplacées par les photos produits réelles.

Comment fonctionneront les commandes ?

Le parcours prévu est Instagram → site → confirmation via WhatsApp ou formulaire une fois les coordonnées officielles ajoutées.

Le paiement à la livraison est-il prévu ?

Oui, sous réserve du partenaire de livraison retenu pour le lancement.
